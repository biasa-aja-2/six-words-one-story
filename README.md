One complete story in exactly six words, for the
[Six Words, One Story](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410)
bounty on make.fun:

> Bought a ring. Sold it. Twice.

Three beats carry a whole arc: hope (bought), failure (sold), and
repetition (twice) that reframes the first two beats and leaves the
why for the reader to fill in. The entry program writes that line to
`/output/entry.txt`.

## Run

```sh
python3 main.py
# writes /output/entry.txt — six words, 30 characters
```

`main.py` is pure Python standard library, deterministic, no network.

## Layout

- `main.py` — the entrypoint; defines the story, gates it at exactly six words and 1–60 characters, writes `/output/entry.txt`
